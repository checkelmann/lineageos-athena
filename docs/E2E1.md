# e2e1 — experimental installation-test build

Device: **Amazon Echo Show 8, 2nd Gen only**, codename **athena**.
Android 11 / LineageOS 18.1, stock 32-bit ARM kernel 4.4.146.

Artifact: `lineage-18.1-20261019-UNOFFICIAL-e2e1-athena.zip`.

This build is intended for end-to-end installation testing on an already prepared
device with working TWRP. It has **not yet been installed or boot-tested as a ZIP**.
Do not treat successful live development fixes or packaging checks as install success.

## Changes since the original October 19 candidate

- Camera sensor tuning, scene libraries and missing plugin dependencies; preview
  confirmed on the development device with physical privacy off.
- Native read-only thermal HAL using actual sensor temperatures, matching stock
  thermal module and OEM locale-policy restoration helper. No invented thresholds.
- Source-built primary-audio wrapper routing ordinary processed microphone requests
  through the working stock ASR pipeline.
- Additional fail-closed software privacy guard for built-in microphone reads.
  Foreground mute/unmute tests and six native regression tests passed live.
- All prior display/touch, Wi-Fi, Bluetooth-controller, speaker/volume and boot fixes.
- No bundled host ADB authorization key or forced root-adbd; authentication retained.

## Before testing

Read [installation and recovery safety](INSTALL.md). Back up userdata and current
boot/system/vendor partitions first. Never wipe userdata or flash LK/LK2/preloader,
TEE or recovery for this ROM. Verify SHA256SUMS before copying or installing.
Keep stable power and USB access. Existing addon.d scripts need separate review.

After install, verify ADB authorization, boot completion and automatic startup of
Wi-Fi/Bluetooth/audio/camera/thermal without manual service starts. Test voice input
and privacy both ways, real wake-word/command handling, echo cancellation and
screen-off listening. These are release gates, not promises of this build.

## Important limitations

Permissive SELinux, unencrypted userdata configuration, userdebug/public test-key
signing and old stock kernel/vendor security level. The privacy button still also
sends POWER; software mute tests do not certify hardware isolation. Raw/unprocessed
mic capture, Bluetooth pairing/audio profiles, video capture, thermal heat safety,
long-term satellite operation and clean stock-to-Lineage migration are unqualified.

The image includes stock kernel/vendor binaries. Exact corresponding kernel-source
coverage and proprietary redistribution clearance have not been independently
established; this experimental release does not provide a blanket license for
third-party assets. See [provenance and notices](PROVENANCE.md).
